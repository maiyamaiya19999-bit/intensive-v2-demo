Карусель: как собрать картинки

Текст по девяти слайдам у тебя уже есть от помощника «Карусель». Осталось превратить его в картинки. Три пути, выбери свой.

Путь 1. Claude Code на компьютере

  1. Открой Claude Code в папке «Мой блог».
  2. Вставь текст карусели и напиши: «Сделай карусель по этому сценарию: девять слайдов 1080 на 1350, фон тёплый бежевый, заголовки Lora, текст Inter, один коричневый акцент, без рамок и скруглений, в подвале «листай дальше» и номер слайда».
  3. Если у тебя стоит «Дизайн-отдел» из бонусов, напиши просто: «Сделай карусель по этому сценарию скиллом каруселей».
  4. Получишь девять файлов PNG. Проверь, что текст влез и ничего не обрезано.

Путь 2. Платный Claude на компьютере, без Claude Code

  1. Скачай файл «Код для картинок карусели» из файлов шага и прикрепи его в чат Claude скрепкой.
  2. Вставь текст карусели и напиши: «Подставь мой текст в блок CONTENT в этом файле, поставь мой ник в author, выполни код и отдай девять картинок».
  3. Claude сам скачает шрифты, нарисует слайды и пришлёт файлы. Если он спросит разрешение запустить код, разреши.

Путь 3. С телефона, в Canva

  1. Открой Canva, создай «Пост для Instagram» размером 1080 на 1350. Сделай девять страниц.
  2. Фон на всех страницах один: тёплый бежевый, код цвета FAF7F3. Поля по 100 пикселей с каждой стороны.
  3. Заголовки шрифтом Lora жирным, текст шрифтом Inter. Один цвет для акцентов: коричневый 6E543F. Никаких рамок, теней и скруглений.
  4. Сверху на каждой странице твой ник мелко курсивом, снизу «листай дальше →» и номер слайда, например «03 / 09».
  5. Перенеси текст по слайдам один в один. Обложка крупно, остальные слайды: заголовок и две-три строки.
  6. Скачай как PNG и выложи как пост с девятью картинками, добавь подпись из ответа помощника.

Проверь перед публикацией. Обложка читается за секунду. На каждом слайде одна мысль. Текст не залезает на поля. Последний слайд с одним действием.
