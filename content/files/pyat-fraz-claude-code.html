5 фраз, которые я говорю Claude Code

Claude Code — это тот же Claude, только он работает с папками и файлами у тебя на компьютере. Пишешь обычными словами — он делает.

1 · Первая проверка (шаг 1.3)
Привет, это моя папка для блога. Создай в ней файл заметки.md и напиши туда "команда на месте".
2 · Сохранить готовое (модули 4–7)
Сохрани это в папку "Мой блог/сценарии".
3 · Собрать темы (шаг 6.1)
Добавь в базу и адаптируй под меня.

Пиши это вместе со ссылкой, скрином или расшифровкой чужого ролика.

4 · Смонтировать ролики (шаг 8.2)
Смонтируй всё из input.
5 · Поставить всю команду (шаг 11.1)
Прочитай файл УСТАНОВЩИК.md и сделай всё, что там написано.

Открывай Claude Code всегда в папке «Мой блог» — там живут все файлы команды. Не понравилось — скажи одной фразой, что поправить.
